# CLEAR IT
CLEAR IT — программа, которая помогает быстрее разбираться в больших текстах.

Функції першої версії
С помощью программы можно:
 • SUMMARIZE — сократить текст.
 • EXPLAIN — объяснить сложную информацию простыми словами.
 • EXTRACT — выделить самое важное.

Также можно выбрать длину ответа.

Как запустить
1. Установить необходимые библиотеки.
2. Запустить программу командой streamlit run app.py.20:58

Технології
Python, Streamlit, OpenAI API.
